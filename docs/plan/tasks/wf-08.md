# WF-08 Orca 真实演练与发布候选

## objective

证明版本匹配的 Orca 生命周期能承载新流程，并整理可交付证据。

## context

- [行为规格](../../design/skill-workflow-spec.md)：正本合同，验收 AC15 及 AC02—AC10 的真实路径。
- [总体计划](../skill-workflow-plan.md)：阶段、依赖、隔离和交付范围。
- [模块分析](../analysis/skill-workflow.md)：集成关系。
- [上游研究](../../research/upstream-skill-map.md) 与 [Orca 研究](../../research/orca-mechanisms.md)：取证版本和原文来源。

## path

隔离测试仓库与测试 tracker；仓库外去敏证据；docs/plan/reviews；必要修复须回到所属任务。

仓库内路径相对仓库根；隔离仓库、测试 tracker 与仓库外证据按现场资源指针定位。涉及两语言包的文档同时修改，脚本保持字节相同。实施前核对实际路径；范围扩大回到 spec 审阅。

## delivery

现场记录 CLI/宿主版本和能力；限定测试资源；保存消息与产物证据；不访问用户真实邮箱；根据授权交付 PR/合并，禁止凭演练失败自动重派。

## verification

真实普通 ask→结束 turn→唤醒→用户答复→reply；chart/work；HITL 与 AFK；隔离 worktree；worker_done 后验收；中断恢复；只设计终点；最终 CI 与去敏检查。

由独立 verify 对照 spec 审阅，记录命令/输入、实际结果和证据；未执行填未验证。不得仅根据代码形状或关键字宣布行为通过。

## completion

产物可审阅，适用验收条目有证据，blocking findings 已修复，依赖连接无 stub，状态才可改 done。PR 和合并以用户授权为准。
