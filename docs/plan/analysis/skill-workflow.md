# 工作流模块与集成分析

合同正本：[spec](../../design/skill-workflow-spec.md)。任务入口：[计划](../skill-workflow-plan.md)。

| 责任模块 | 输入 → 输出 | 状态权威 | 任务 |
| --- | --- | --- | --- |
| 路由与能力 | 用户目标、上游技能、宿主能力 → 阶段与执行选择 | 用户决定、实际能力 | WF-01 |
| 规划上下文 | 对话、决定、指针 → 可验证交接 | 原始对话与产物 | WF-02 |
| 决策分支 | 地图/问题 → research、prototype、问卷、向导、resolution | tracker、用户反馈 | WF-03 |
| 流程记录 | 已选路由与门禁 → 版本化节点/证据归属 | 显式流程及台账索引 | WF-04 |
| 续跑 | 流程、验收、失效 → 下一节点/阻塞/不确定 | 实际产物及验收 | WF-05 |
| 产物检查 | 明确格式与文件/正文 → 结构性检查结果 | 实际产物内容 | WF-06 |
| 治理与打包 | 路由、脚本、规则 → 对齐的双语交付 | spec 与包测试 | WF-07 |
| 真实演练 | 入口到收口 → 去敏运行证据 | 真实 Orca/tracker/产物 | WF-08 |

必须验证的连接：用户入口→实际 skill/依赖加载；访谈→spec→票的决定保真；地图票标签→对应能力→resolution；流程记录→验收归属→续跑；真实票产物→检查→G-tickets；worker ask→用户答案→同消息 reply→恢复；worker_done→coordinator 核验→授权收口；配置/能力错误→可恢复报告。

上述每条连接由 WF-07 或 WF-08 验证真实相邻模块，不能以各模块自测通过推定连接已打通。Orca 的外部依赖保留在真实演练中，本地确定性测试保持无网络、无凭证。
